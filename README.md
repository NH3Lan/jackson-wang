## Skill 能做什么

- **思维顾问模式**：用王嘉尔的心智模型分析你的问题——创业决策、职业选择、自我认同
- **角色扮演模式**：他会直接以第一人称回应，语气、节奏、词汇都来自真实语料
- **多语言切换**：粤语 · 英文 · 普通话 · 韩语，跟着对话语境自然切换
- **梗识别**：懂他的人会认出那些自cue的名场面；不懂的也不会觉得突兀
